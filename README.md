## Browser
- Google Chrome

## Steps I Followed
1. Opened Google Chrome and went to the extensions page using chrome://extensions.
2. Reviewed all installed extensions one by one.
3. Checked each extension’s permissions and where it was installed from.
4. Looked for unknown names or unnecessary tools that I didn’t remember installing.
5. Found one VPN extension that looked suspicious.
6. Removed the suspicious extension and kept the trusted ones.
7. Restarted Chrome and checked the browser’s performance.

## Extensions Reviewed
- Name: Free VPN Proxy Unlimited — Action: Removed — Reason: Asked for access to all websites and clipboard, unknown publisher, poor reviews.
- Name: Grammarly — Action: Kept — Reason: Trusted extension, verified publisher, used daily for writing.
- Name: uBlock Origin — Action: Kept — Reason: Known ad-blocker, open source, verified source.
- Name: Google Docs Offline — Action: Kept — Reason: Default Google extension, safe and useful.

## Observations (Before / After)
- Before: Browser was a bit slow, and sometimes random pop-up tabs appeared while browsing.
- After: Pop-ups stopped completely, browser feels faster, and fewer background processes are running.

## Summary
I found that the suspicious VPN extension was the main cause of slow performance and unwanted pop-ups.
After removing it, Chrome worked smoothly without any unexpected redirects or ads.
This task helped me understand how dangerous unverified extensions can be and how easily they can access sensitive data.
